# Landing page do Marvin

Site estático independente, sem build ou dependências. Para deploy na Vercel, selecione o diretório raiz apps/landing, preset Other e nenhum comando de build. Não configure variáveis da plataforma financeira.

Para servir localmente: python3 -m http.server 8080 --directory apps/landing.

O link de instalação acompanha docs/deployment.md. Redes confirmadas ficam no rodapé; LinkedIn e X aguardam URLs exatas. Nenhum analytics ou cookies.
